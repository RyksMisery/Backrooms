# Канон звука

## Единственный источник правил

Продуктовый профиль фонового звука находится в
`modules/audio_module.gd`. Он владеет WAV-ассетами, базовыми уровнями,
порогом тишины, расчётом плотности светильников, сглаживанием громкости и
звуком фактического мерцания.

Уровень передаёт звуковому модулю игрока и окончательный список светильников.
Сам уровень не создаёт отдельный гул, не копирует dB/радиусы и не рассчитывает
плотность ламп. При перемещении модульной геометрии список мировых позиций
светильников обновляется через API звукового модуля.

Изменение общего WAV, громкости или алгоритма выполняется только в
`audio_module.gd` и применяется ко всем уровням без изменения их scripts.
Локальное звуковое исключение допустимо только как явно документированный
profile override конкретной области или загадки.
