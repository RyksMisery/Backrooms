# АРХИВ: префабы (вариант 1) — НЕ АКТУАЛЬНО

> Этот подход ЗАМОРОЖЕН. Актуальная архитектура — occupancy-сетка
> (`level_areas.gd`, см. `plan_areas_v2.md`). Файл сохранён как справка по
> размерам/идеям, которые можно переиспользовать внутри occupancy-подхода.
> Не строить новую генерацию на этой модели «комнат-коробок».

## Почему заморожено

Старый подход собирал уровень из 9 готовых самостроящихся префабов-коробок.
Минусы: дублирующиеся стены встык, заделка щелей постфактум, негибкая
стыковка. Заменён единой occupancy-сеткой, где смежные области делят одну
стену с одним проёмом, а пол/потолок — цельные плиты.

## Переиспользуемые идеи (перенесены в актуальные доки)

- Окна-пролазы 1×1 от пола → `gameplay.md` (видимые-но-недоступные зоны).
- Балки по сетке / в углах → деталь occupancy-билдера.
- Провал → `place_pit` в `plan_areas_v2.md` + механика в `gameplay.md`.
- Размеры/клиренс света → `lights.md`.
