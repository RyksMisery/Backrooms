# Лаборатория «щелчка оси» — anfilada_axis_lab

> Первый шаг концепта `docs/concept_anfilada.md`. Ветка:
> `feature/anfilada-axis-lab`. Проверяем одно: ощущение сборки оси
> (биения гулов → унисон → линия открылась → слом за спиной).

## Состав

- `modules/axis_module.gd` — вантаж-точка + конус взгляда + линия-коридор,
  колбэки `assembled / broken / completed`. Геометрию и двери не строит.
- `anfilada_axis_lab.gd/.tscn` — стандартная область 15×15 (полный пакет
  `standard_area_module`), внутри три перегородки 0.5 панели поперёк Z с
  проёмами, смещёнными ступенькой. Центры проёмов коллинеарны: ось видна
  только с одной диагональной точки у северо-западного угла.

## Геометрия (клетки)

| Перегородка | z (клетки) | центр проёма x (клетки) | проём |
|---|---|---|---|
| 1 | 4 | 4.5 | свободный, 2 клетки, офисная высота |
| 2 | 8 | 7.5 | офисный `office_new` с закрытой дверью |
| 3 | 12 | 10.5 | свободный, 2 клетки, офисная высота |

- Вантаж: `(2.775, 1.2)` м, радиус 1.1 м, направление взгляда `(0.6, 0.8)`
  по XZ, конус 15°.
- Линия оси: вантаж → `(14.25, 16.5)` м, полуширина коридора 1.4 м.
- Спавн: `(9.375, 2.2)` м — в первой полосе, в стороне от вантажа.

## Правила лаборатории

- Дверь средней перегородки закрыта (коллизия), пока ось не собрана.
- Сборка: игрок в вантаж-объёме и смотрит вдоль оси → унисон гулов,
  дверь открывается (лист скрыт, коллизия снята).
- Удержание: идти вдоль линии; слом — выход из коридора линии или взгляд
  назад (`dot < -0.25`). Слом возвращает дверь.
- Завершение: дойти до конца линии — дверь остаётся открытой, ось гаснет.

## Звук (документированный локальный override канона)

`axis_module` добавляет второй слой канонического WAV-гула
(`fluorescent_lamp_hum.wav`) с pitch-offset: вдали от вантажа — быстрые
биения с основным гулом, у вантажа offset → 0 (биения замедляются и
исчезают), при сборке — чистый унисон с лёгким подъёмом громкости.
Основной профиль `audio_module` не изменяется.

## Крутилки (константы `axis_module.gd`)

- `APPROACH_RADIUS` (9 м) — откуда слышен слой биений.
- `DETUNE_MAX` (0.045) / `DETUNE_CURVE` (1.6) — скорость биений и кривая
  схождения.
- `VANTAGE_RADIUS`/`cone_deg` — в спеке оси (1.1 м / 15°).
- `LOOK_BACK_DOT` (−0.25), `CORRIDOR_SLACK` (0.5 м), `END_RADIUS` (1.3 м).

## Критерий успеха

Тестер без объяснений: замечает биения → находит точку → ловит унисон →
проходит линию. После первого прохода сам ищет вторую ось глазами.
Если унисон не читается — сначала крутить `DETUNE_MAX`/`HUM_DB`,
не добавляя визуальных подсказок.

## Известные упрощения лаборатории (не канон)

- Внешние проёмы перегородок — свободные (`opening_freeform`), их центры
  (4.5 / 10.5) стоят на границах клеток ради коллинеарности оси; сеточный
  якорь обязателен только для дверного/офисного класса — средний проём
  канон соблюдает (7.5 → якорь 7.5).
- Слом оси пока только возвращает дверь; перестроение за спиной — следующий
  шаг после допуска щелчка.
- Светильники стандартной сетки могут визуально соседствовать с
  перегородками — для лаборатории допустимо.
